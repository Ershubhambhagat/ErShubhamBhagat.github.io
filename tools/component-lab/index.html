Component lab

Every shared component state, rendered once. This page is not linked from the portfolio, is excluded from the sitemap and carries noindex. It exists so states that no section triggers can be checked in a real browser instead of by reading CSS.

Buttons Cards Badges Filters Search Timeline Modals Toasts Images

Buttons

Six variants at three sizes, then the loading, disabled, icon-only and link states. Loading must set aria-busy and keep the label; disabled must refuse activation.

Cards

Standard, elevated, featured, compact and horizontal, then the skeleton and the media states: a working image, a missing file that must remove itself, and no image at all.

Badges

Seven variants at three sizes, an interactive badge with aria-pressed, and count badges (including the invalid count that must be hidden rather than printed).

Filters

One panel with all five group types (single, select, multiple, checkbox, range), collapsible, with a result count and active chips. The second panel is always expanded and uses apply mode.

Search

The shared field with suggestions, keyboard listbox and a status line. Typing “re” must offer React and Redux; Enter selects the active option.

Timeline

The same four events in all four layouts: vertical, horizontal, compact and grouped. Events carry a badge, a details disclosure, an action and an image so those slots are exercised too.

Modals

Open each size and the confirm/preview helpers. While a dialog is open the page scroll must be locked; Escape, the backdrop and the close button must all close it and restore focus.

Toasts

Four tones, a stack capped at three visible, auto-dismiss, and hover pause. Pausing must hold the remaining time, not restart it.

Images

The shared image helper: lazy by default, reserved width and height, an eager variant for above-the-fold use, and a broken source that must be removed rather than left as a broken icon.
